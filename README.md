## 🚀 How to Run Locally

### Option 1: Instant Preview (Zero Dependencies)
Simply double-click `index.html` in your file explorer to open it directly in Google Chrome, Edge, or Brave. Everything runs client-side with zero external build tools!

### Option 2: Run via Node / NPM Local Server
```bash
# Using npx serve
npx serve .

# Or using Python's built-in web server
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploy to Production (In Under 60 Seconds)

### Deploy to Vercel
1. Install Vercel CLI (optional) or push to a GitHub repository:
```bash
git init
git add .
git commit -m "feat: initial portfolio release"
git branch -M main
git remote add origin https://github.com/Nithin560/portifolio.git
git push -u origin main
```
2. Connect the repo on [vercel.com](https://vercel.com) — zero configuration needed! It deploys immediately.

### Deploy to GitHub Pages
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment**, select `Deploy from a branch` and choose `main` / `root`.
3. Click **Save**. Your site is live at `https://nithin560.github.io/portifolio/`!
